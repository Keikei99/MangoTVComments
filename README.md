# MangoTV Comments — 芒果TV弹幕抓取工具

通过芒果TV公开的播放接口抓取指定视频的全量弹幕，导出为 CSV 与 JSON。

## 特性

- 只需一个播放页链接，自动解析 `cid` / `vid`
- 自动获取视频标题与时长，按时长决定抓取范围
- 跟随接口返回的 `next` 指针推进分片，避免漏段
- 按弹幕 ID 去重、按时间排序
- 失败自动退避重试，可自定义请求间隔
- 同时导出 CSV（UTF-8 BOM，Excel 可直接打开）和 JSON（含视频元数据）

## 环境要求

- Python 3.8+
- `requests`

```bash
pip install requests
```

## 使用方法

```bash
python3 mgtv_danmaku.py "https://www.mgtv.com/b/815824/24328855.html"
```

可选参数：

```bash
python3 mgtv_danmaku.py "<url>" --out data --delay 0.3
```

| 参数 | 说明 | 默认值 |
| --- | --- | --- |
| `url` | 芒果TV播放页链接（必填），形如 `https://www.mgtv.com/b/<cid>/<vid>.html` | — |
| `--out` | 输出目录 | `data` |
| `--delay` | 每个分片之间的请求间隔（秒） | `0.3` |

运行过程中会逐分片打印进度：

```

cid=815824 vid=24328855 时长=59:14 (3554s)
  [00:00:00.000] 本片段    5 条 (新增    5) | 累计 5
  [00:01:00.000] 本片段    8 条 (新增    8) | 累计 13
  ...
完成: 共 87 条弹幕
```

## 输出格式

文件名为 `<vid>_<视频标题>.csv` / `.json`，位于输出目录下。

### CSV 字段

| 字段 | 说明 |
| --- | --- |
| `id` | 弹幕唯一 ID |
| `uid` | 发送者用户 ID |
| `time_ms` | 弹幕在视频中的位置（毫秒） |
| `timestamp` | 同上，格式化为 `HH:MM:SS.mmm` |
| `content` | 弹幕文本内容 |
| `up` | 该条弹幕的点赞数 |
| `type` | 弹幕类型（0 为普通弹幕） |

### JSON 结构

```json
{
  "meta": {
    "cid": "815824",
    "vid": "24328855",
    "title": "大侦探第十一季 轻量版第10期：……",
    "clip_name": "大侦探 第十一季",
    "duration_text": "59:14",
    "duration": 3554
  },
  "count": 87,
  "danmaku": [
    {
      "id": "7633449129759348285",
      "uid": 3263770599,
      "time_ms": 66000,
      "timestamp": "00:01:06.000",
      "content": "看看你那你",
      "up": 0,
      "type": 0
    }
  ]
}
```

## 工作原理

1. **解析链接** — 从 `/b/<cid>/<vid>` 路径正则提取合集 ID 与视频 ID。
2. **获取元信息** — 请求 `pcweb.api.mgtv.com/video/info`，读取视频标题与时长（`59:14` 形式，转换为秒）。
3. **分片拉取弹幕** — 芒果TV的弹幕接口 `galaxy.bz.mgtv.com/rdbarrage` 以 60 秒为一个分片返回数据，参数 `time` 为分片起始毫秒。脚本从 0 开始，优先跟随响应中的 `next` 字段推进，缺失时回退到 `+60000`，直到超过视频时长。
4. **去重与导出** — 以弹幕 `ids` 去重，按 `time_ms` 排序后写出 CSV 与 JSON。

结尾连续 5 个空分片且已超过视频时长时提前结束，避免无谓请求。

## 示例数据

`data/` 目录内是对以下视频的抓取结果，可作为输出格式参考：

- 视频：大侦探第十一季 轻量版第10期
- 链接：`https://www.mgtv.com/b/815824/24328855.html`
- 结果：87 条弹幕，来自 67 个不同用户，时间跨度 00:00:00 – 00:52:04

条数偏少是因为该视频为「轻量版」剪辑，本身弹幕稀疏（中段与结尾存在多个空分片），并非抓取遗漏。

## 批量抓取整季

以下接口可列出某合集下所有分集的 `vid`，据此循环调用本脚本即可抓取整季：

```
https://pcweb.api.mgtv.com/list/master?cid=<cid>&pn=1&ps=60
```

## 注意事项

- 请求已带上 `Referer` / `User-Agent` 头；如遇限流，适当调大 `--delay`。
- 弹幕接口返回的是芒果TV当前对外展示的数据，热门视频可能存在服务端抽样，条数不等于历史累计发送量。
- 本项目仅用于学习与数据分析，请遵守芒果TV的服务条款，勿用于商业用途或高频请求。
